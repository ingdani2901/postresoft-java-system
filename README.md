# PostreSoft - Pastry Shop Management System

PostreSoft is a Java desktop application designed to manage the operations of a pastry shop.  
The system allows users to manage products, customers, and inventory through a simple interface connected to a relational database.

## Features

- Product management
- Customer management
- Inventory control
- Database integration
- User interface for bakery administration

## Technologies Used

- Java
- MySQL / SQL
- NetBeans IDE
- JDBC
- Java Swing (GUI)

## Project Structure

src/ → Application source code  
nbproject/ → NetBeans project configuration  
pasteleria.sql → Database structure  
user-manual-postresoft.pdf → User guide  
project-documentation-postresoft.pdf → Technical documentation  
code-explanation-postresoft.pdf → Code explanation  

## Installation

1. Clone the repository
2. Import the project into NetBeans
3. Create the database using the provided SQL file
4. Configure the database connection
5. Run the application
